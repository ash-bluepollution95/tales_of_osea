## Design Concept Ideas 

This section will frame out the CONCEPT not nesscarily the plans overall, something that maybe should've been done ahead of time but oh well. The look and feel rather than the process or the install or the code. 

- The concept of the idea of the layout is to match the ENERGY of the Litter Box venue site - but not be a single page.
- Mixing the idea of Clean and fantasy but not eye bleeding. 
- A theme color picker would allow for not just dark and light but aesthetic color themes that match the idea of dark modes and pastel but safe for eyes and reading.
- Fonts will depend on accessibility meets whatever the components allow, if we can do google fonts cool if we can't we'll work on it. 


### Extra Agentic Notes 

- If we HAVE to fix a component and are allowed to, we can but the reasoning will be given and permission in the moment, the agent MUST not auto fix it unless it's permission based. 
- An example is: if a background component just needs a little code update to work within the context of the higher versions of Next/node/react, and should be fine otherwise - as long as I say yes and have a good reason towards WHY I need said component - permission at that moment will be granted for the agent to "do their magic" as long as it's linted, and security concious.
